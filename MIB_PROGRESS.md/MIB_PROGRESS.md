# MIB Development Workflow

## Daily Development

1. Open VS Code
2. Run
```bash
npm run dev
```

3. Check Git status
```bash
git status
```

4. Stage changes
```bash
git add .
```

5. Commit
```bash
git commit -m "Your commit message"
```

6. Push
```bash
git push
```

7. Vercel automatically creates Preview Deployment

8. Test on:
- Laptop
- iPhone

9. Merge into `main` only after everything is verified.
